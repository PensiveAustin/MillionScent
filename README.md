# Million Scent

Frontend-only demo of a perfume shop. No backend, no real payments.

- `index.html` is the whole site; bottle photos are in `images/` (front.png, side.png). Originals are in `images/original/`
- Open `index.html` in a browser, or deploy with GitHub Pages / Vercel / Netlify
- Features: bottle shelf with spin-to-front on hover/tap, collection filters, search, product popup, bag drawer, demo checkout
- Fragrance data (names, prices, notes) is the `F` array near the top of the `<script>` section
